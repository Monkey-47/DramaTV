# AI Drama Canvas

一个为面试准备的 **React + TypeScript + React Flow 无限画布 Demo**：用可视化节点编排 AI 短剧分镜、剧情流转、提示词和预览效果。

## 为什么做这个 Demo

目标公司业务涉及「无限画布 + AI 短剧生产」。这个项目刻意覆盖了相关核心能力：

- 无限画布编辑体验
- 自定义场景节点
- 剧情连线和转场标注
- 场景详情编辑面板
- AI 生成画面的 mock 流程
- 短剧顺序预览模式

UI 风格参考苹果官网简介页：简洁留白、柔和渐变、玻璃拟态、圆角卡片和克制的动效。

## 技术栈

- React 19
- TypeScript
- Vite
- @xyflow/react（React Flow v12）
- Zustand
- TailwindCSS v4

## 功能亮点

### 1. 无限画布

基于 React Flow 实现缩放、平移、拖拽、连线、小地图和视图适应。

### 2. AI 短剧场景节点

每个节点代表一个短剧分镜，包含：

- 场景标题
- 场景类型：开场 / 普通 / 高潮 / 结局
- 场景描述
- AI 画面提示词
- 角色对白
- 角色列表
- 时长
- AI 生成画面 mock

### 3. 剧情流转连线

自定义边展示转场类型：

- 淡入淡出
- 直接切换
- 溶解

点击连线标签可以快速切换转场类型。

### 4. 侧边栏实时编辑

点击画布节点后，右侧面板会显示完整场景信息。修改表单后，节点内容会实时同步。

### 5. 预览模式

点击「播放预览」后，会按剧情流顺序展示短剧分镜，适合面试时快速演示「编辑态 → 成片预览」的产品闭环。

## 面试讲解建议

可以按这个顺序介绍：

1. **业务理解**：AI 短剧生产不是单点生成，而是「分镜编排 + 角色对白 + 提示词 + 转场 + 预览」的工作流。
2. **为什么用 React Flow**：它天然适合 infinite canvas 和节点编排，能快速实现专业编辑器体验。
3. **状态管理设计**：画布节点和表单编辑共享 Zustand store，避免组件间层层传参。
4. **可扩展性**：AI 生成现在是 mock，未来可接入真实生成接口；节点数据结构已经预留 prompt、角色、对白等字段。
5. **产品感**：参考苹果官网风格做了简洁高级的 UI，而不是默认工程模板。
